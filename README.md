# 💖 Página Web de San Valentín 2026

Una hermosa página web interactiva para celebrar el Día de San Valentín, creada con HTML, CSS y JavaScript vanilla.

## ✨ Características

### 🎨 Diseño Premium
- Fondo con gradiente animado que cambia constantemente
- Efectos glassmorphism modernos
- Tipografías elegantes (Playfair Display & Poppins)
- Paleta de colores vibrantes y románticos

### 💝 Componentes Interactivos

#### 1. Corazón Clickeable
- Gran corazón SVG animado que pulsa
- Al hacer clic, muestra un mensaje romántico en modal
- Explosión de corazones al interactuar
- Efecto parallax 3D con el movimiento del mouse

#### 2. Galería de Tarjetas Románticas
- 8 hermosas frases de amor de autores famosos
- Animaciones 3D con rotación y escala
- Auto-rotación cada 5 segundos
- Navegación con flechas y puntos indicadores
- Efecto de explosión de corazones al cambiar tarjetas

### 🎭 Efectos Especiales
- Corazones flotando constantemente en el fondo
- Partículas que aparecen al hacer scroll
- Confeti aleatorio de corazones
- Animaciones suaves en toda la página

### ⌨️ Atajos de Teclado
- `Enter` o `Espacio`: Abrir mensaje romántico
- `Escape`: Cerrar mensaje

## 🎨 Personalización

### Cambiar el Mensaje Romántico
Edita `index.html` en las líneas 56-64:
```html
<p class="message-text">
    Tu mensaje personalizado aquí
</p>
```

### Agregar Más Frases
Edita `script.js` y agrega objetos al array `loveCards` (línea 22):
```javascript
{
    icon: '💖',
    text: 'Tu frase aquí',
    author: '- Tu Nombre'
}
```

### Cambiar Colores
Edita las variables CSS en `styles.css` (líneas 8-20):
```css
:root {
    --primary-pink: #ff006e;
    --secondary-pink: #ff4d8f;
    /* ... más colores ... */
}
```
